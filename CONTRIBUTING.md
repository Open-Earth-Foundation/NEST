# Contributing

Anyone may open an issue, a Discussion or a pull request. You do not need to
be added to the repository to do any of these.

Pull requests to `main` need one approving review. Partners who maintain a
folder here are listed in CODEOWNERS and review changes to their own folder.

Every document starts with one line giving its status: Draft, Proposed,
Accepted or Experiment. Draft is the default. Please keep the line when you
edit, and change it only through a pull request that says why.

By contributing you agree that your contribution is licensed under the
repository licence for its file type (Apache-2.0 for code, CC BY 4.0 for
documents), unless the folder's README states a different licence.

Material promoted from the consortium's private workspace carries a line
naming the source commit, so that provenance is visible.
